Antares Yuan's HCDE 439 Physical Computing Page!

Hi, I'm Antares Yuan! I'm an HCDE student at the University of Washington on the HCI track, and most of my work so far has been on AI products and agent evaluation. I'm taking this class to finally get my hands on hardware and build things that exist off the screen.

Assignment 1: Blink!

Three red LEDs that light up one at a time, then all flash together.

Assignment 2: Fade!

Three LEDs that fade on one after another, and a button that makes them run the other way.

Assignment 3: Input Output!

A light sensor that turns a servo like a gauge and turns on a night light when the room gets dark.
